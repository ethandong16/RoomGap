# RoomGap · 空闲教室

面向天津科技大学同学的静态教室查询网站。按日期、校区和节次筛选，查看整段空闲的教室及全天安排。支持手机、键盘操作和按日期加载数据。

```powershell
.\run-web.ps1
```

运行后访问 http://127.0.0.1:4173 。需要 Node.js 20+，网站本身无需安装依赖。首次构建和以后每次构建都会检查数据完整性。

- [网站运行、部署和更新说明](WEBSITE.md)
- [数据格式](DATA-FORMAT.md)
- [采集与刷新](COLLECT.md)
- [采集范围和结果](data/README.md)

当前学期为 2026-08-31 至 2027-01-17，共140天。学校目录共有623个教室及资源，网站默认筛选其中384个普通或类型未注明的候选教室。无已记录占用不代表允许自习或实际开放。

网站源文件在 site/，生成文件在 dist/。对外仅部署 dist 内的文件。学校登录配置和采集源记录不属于网站部署内容。
